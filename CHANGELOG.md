# Changelog

## 1.1.0 — 2026-09-15

- Three design themes: Modern, Classic and Minimalist; each works in Light and Dark modes.
- Dedicated Appearance page and a quick brightness toggle.
- Automatic hourly/daily/weekly JSON backups (daily default), with an Off option and Back up now.
- UTC filenames organized by month under Downloads/Locus/Backups.
- Completed-download status, interruption errors and worker-restart recovery.
- Missed scheduled backups catch up once when Chrome resumes.
- First-run guided tour with practice checkbox/slider, skip/back/next and replay.
- Printable in-app user guide and USER-GUIDE.md.
- Existing 1.0 JSON backups remain compatible; new preferences use safe defaults.
- Added alarms/downloads permissions; no host permissions or remote services.
- GitHub link now points to evoknow-ai/locus.
- Expanded automated suite from 15 to 28 tests. Live Chrome visual QA remains pending.

## 1.0.0 — 2026-09-15

Initial Locus release: local projects, optional dates, unset/0–100% progress,
alphabetical/date/custom ordering, draggable checklists, unlimited note counts,
project and task timers, manual time editing, reports with PDF printing,
validated JSON import/export, offloading and one recovery snapshot, themes,
credits, MIT License and feature regression checklist.
